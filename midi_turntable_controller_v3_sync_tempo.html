How to use this controller

This is a single-file demo UI that behaves like a dual turntable controller. It can play audio, scratch by grabbing the wheels, and can optionally send MIDI CC/Note messages through the browser’s Web MIDI API.

  • Start Audio Engine first (required by browsers).
  • Library to import multiple files (WAV/MP3/FLAC) and load to Deck A/B.
  • Load A / Load B still works for quick single-file loading.
  • Scratch: press/hold on a wheel, drag left/right. Release to continue.
  • Wheel Mode: Vinyl = scratch (scrub time), Jog = nudge (temporary rate).
  • Pads: first tap sets a hot-cue, next taps jump to it.
  • MIDI: click Connect MIDI and choose an output + channel.

Note: Web MIDI usually requires a secure context (https/localhost). If MIDI doesn’t connect from a local file, run a quick local server: python -m http.server then open the localhost URL in Chrome.
